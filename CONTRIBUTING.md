# Como contribuir

1. Crie um fork e uma branch curta para a mudança.
2. Mantenha fixtures e exemplos totalmente fictícios.
3. Execute `npm run check` e `npm test`.
4. Explique no pull request o comportamento alterado e os testes realizados.

Mudanças no contrato de dados devem atualizar em conjunto o schema, a validação, o exemplo e a documentação.
