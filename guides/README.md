# Guias editoriais

Esta pasta reúne critérios de conteúdo que orientam a criação e a revisão de currículos. Eles complementam o contrato técnico do projeto sem substituir o JSON Schema.

- [`resume-creation.md`](resume-creation.md): método canônico para montar um currículo claro, verificável e compatível com ATS.

O guia pode ser lido no terminal com `npm run guide` e é incorporado ao pacote local criado pelo comando `assist`.
